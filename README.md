# Хидаятым

Сайт-воспоминание. Работает как обычный сайт и как приложение (PWA) с иконкой лилии.

## Как выложить на GitHub Pages
1. Создай новый репозиторий на github.com (например, `hidayat`), поставь Public.
2. Нажми **Add file → Upload files** и перетащи ВСЕ файлы и папку `icons` из архива (после распаковки). Файл `index.html` должен лежать в корне репозитория.
3. Нажми **Commit changes**.
4. Открой **Settings → Pages**. В **Source** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
5. Через 1-2 минуты сайт появится по адресу `https://ТВОЙ_НИК.github.io/hidayat/`.

## Как поставить как приложение
- **Android (Chrome):** открыть ссылку, меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
- **iPhone (Safari):** открыть ссылку, кнопка «Поделиться» → **На экран «Домой»**.
